Refinamento manual

Pinte a imagem original: as marcas verdes Keep estão sempre protegidas. Escolha Apagar marcas para limpar uma área e pintá-la novamente.

A seleção se expande a partir de onde você clica e para em cores fora da tolerância ou pixels transparentes. Não saltará através de um limite para uma cor correspondente do outro lado. Este limite não afeta a remoção automática do fundo. Valores mais baixos criam limites mais rigorosos; as alterações se aplicam na próxima vez que você clicar.

Fluxo de trabalho recomendado e atalhos de teclado

Fluxo de trabalho recomendado

  1. Carregue uma imagem e, em seguida, selecione Remover Fundo para experimentar o Fine AI por padrão. Mude para a IA original e execute-a novamente para comparação; para fundos sólidos, quadriculados ou listrados, você também pode usar a detecção de cores.
  2. Verifique o contorno do assunto e as lacunas incluídas no painel Resultado. Mude para um fundo de visualização branco ou escuro para detectar os pixels de borda restantes.
  3. Utilização Manter para restaurar partes do assunto que foram removidas, e Remover para limpar qualquer fundo restante.
  4. Deixe a seleção Smart ativada para áreas claramente delimitadas. Ele seleciona apenas os pixels conectados e não cruza um limite de cores diferentes.
  5. Para cabelos, linhas finas, pequenos detalhes ou pixels de borda teimosos, desative a seleção inteligente, reduza o tamanho da escova e refine localmente. Use Apagar marcas, Desfazer e Refazer para ajustar a qualquer momento.
  6. Quando a borda transparente parecer limpa, baixe o PNG transparente.

A seleção inteligente inclui apenas pixels conectados ao local em que clicou e dentro da tolerância de cor escolhida. Um limite de cor bloqueia a seleção, portanto, o branco correspondente fora de um anel não pode selecionar o branco correspondente dentro dele. Você pode usar a seleção Inteligente com Manter e Remover; clique em cada área desconectada separadamente. Os contornos vermelhos mostram Remover áreas e os contornos verdes mostram Manter áreas. Pode mostrá-los ou ocultá-los independentemente, e eles nunca são incluídos em downloads. Mantenha as áreas prioritárias, portanto, remova as ações para ignorá-las. Escolha Apagar marcas para limpar qualquer tipo de marca localmente e, em seguida, pinte novamente. Desative a seleção inteligente para edições precisas de pincel de 1 pixel.
Use a roda do mouse para ampliar a imagem original e, em seguida, arraste para deslocar; ambos os painéis permanecem alinhados. Amplie até 3200% e use o Ajustar para retornar à imagem completa. As teclas de seta movem o pincel um pixel; o espaço pinta. Pressione Ctrl / ļ + Z para desfazer.
