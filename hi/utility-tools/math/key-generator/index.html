सुरक्षित कुंजी जनरेटर

ब्राउज़र Web Crypto API से क्रिप्टोग्राफ़िक रूप से सुरक्षित API कुंजियाँ, एन्क्रिप्शन कुंजियाँ और एक्सेस टोकन बनाएँ। HEX, Base64, Base64URL या Base32 चुनें; पूरी प्रक्रिया इसी डिवाइस पर रहती है।

⚠ यह टूल मशीन द्वारा पढ़े जाने वाले क्रेडेंशियल के लिए है, याद रखने वाले लॉगिन पासवर्ड के लिए नहीं। अपनी सुरक्षा आवश्यकता के अनुसार पर्याप्त बाइट चुनें।
⛔ यह ब्राउज़र crypto.getRandomValues का समर्थन नहीं करता, इसलिए सुरक्षित कुंजियाँ नहीं बन सकतीं। नवीनतम Chrome, Firefox, Safari या Edge इस्तेमाल करें।
आरंभ हो रहा है…

रैंडम स्रोत: crypto.getRandomValues(), जो क्रिप्टोग्राफ़िक रूप से सुरक्षित है। रीफ़्रेश के बाद कुंजी नहीं रहती; उसे कॉपी या डाउनलोड करके सीक्रेट मैनेजर में रखें।

एन्कोडिंग प्रारूप

एक ही रैंडम बाइट को अलग टेक्स्ट एन्कोडिंग में दिखाया जा सकता है। URL, JSON, कॉन्फ़िगरेशन फ़ाइल या प्रोटोकॉल के अनुसार प्रारूप चुनें।

HEX2×
0-9 a-f

हर बाइट को दो हेक्साडेसिमल अक्षरों में दिखाता है। लंबाई तय रहती है और लगभग सभी भाषाएँ व टूल इसे समर्थन देते हैं।

उपयुक्त: कॉन्फ़िगरेशन फ़ाइल, कमांड लाइन, लॉग और डिबगिंग।

Base64≈1.34×
A-Z a-z 0-9 + / =

कॉम्पैक्ट बाइनरी-टू-टेक्स्ट प्रारूप, लेकिन URL या फ़ाइल नाम में +, / और = को एस्केप करना पड़ता है।

उपयुक्त: JSON/XML ट्रांसपोर्ट और सामान्य टेक्स्ट स्टोरेज।

Base64URL≈1.34×
A-Z a-z 0-9 - _

- और _ इस्तेमाल करने वाला तथा = पैडिंग हटाने वाला URL-सुरक्षित Base64।

उपयुक्त: JWT, OAuth टोकन, कुकी और URL पैरामीटर।

Base32≈1.6×
A-Z 2-7

केस से स्वतंत्र और भ्रमित करने वाले 0/O, 1/I/L अक्षरों से मुक्त।

उपयुक्त: TOTP सीक्रेट, DNS रिकॉर्ड, बारकोड और हाथ से प्रविष्टि।

अक्सर पूछे जाने वाले प्रश्न

क्या यह कुंजी जनरेटर सुरक्षित है?

हाँ। यह Math.random के बजाय ऑपरेटिंग सिस्टम के क्रिप्टोग्राफ़िक सुरक्षित रैंडम स्रोत वाले crypto.getRandomValues का उपयोग करता है।

क्या कुंजियाँ सर्वर पर भेजी या रिकॉर्ड की जाती हैं?

नहीं। बनाना और एन्कोडिंग ब्राउज़र में होता है, इतिहास नहीं रखा जाता और रीफ़्रेश पर परिणाम मिट जाते हैं।

क्या इन्हें लॉगिन पासवर्ड बना सकते हैं?

ये API कुंजी, एन्क्रिप्शन कुंजी और टोकन जैसे मशीन-पठनीय सीक्रेट के लिए हैं। इंसानों द्वारा टाइप किए जाने वाले पासवर्ड के लिए पासवर्ड मैनेजर इस्तेमाल करें।

क्या दो कुंजियाँ एक जैसी हो सकती हैं?

सैद्धांतिक रूप से संभव है, पर सुझाई गई लंबाई पर संभावना नगण्य है। 32-बाइट कुंजी के 2^256 संभावित मान होते हैं।

कुंजी को कैसे सुरक्षित रखें?

लंबे समय की कुंजियाँ सीक्रेट मैनेजर या सुरक्षित पर्यावरण चर में रखें; सोर्स कंट्रोल, चैट या लॉग में न डालें और समय-समय पर बदलें।

कुंजियाँ केवल इस ब्राउज़र में बनती हैं और सर्वर पर अपलोड नहीं होतीं।
