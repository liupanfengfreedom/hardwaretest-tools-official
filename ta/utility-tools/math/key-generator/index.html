பாதுகாப்பான சாவி உருவாக்கி

உலாவியின் Web Crypto API மூலம் குறியாக்கவியல் பாதுகாப்பான API சாவிகள், குறியாக்கச் சாவிகள் மற்றும் அணுகல் டோக்கன்களை உருவாக்குங்கள். HEX, Base64, Base64URL அல்லது Base32 தேர்ந்தெடுக்கவும்; அனைத்தும் இந்தச் சாதனத்திலேயே நடக்கும்.

⚠ இந்தக் கருவி இயந்திரம் படிக்கும் இரகசியங்களுக்கானது; நினைவில் வைத்துக்கொள்ளும் உள்நுழைவு கடவுச்சொற்களுக்கல்ல. பாதுகாப்புத் தேவைக்கேற்ப போதுமான பைட்டுகளைத் தேர்ந்தெடுக்கவும்.
⛔ இந்த உலாவி crypto.getRandomValues-ஐ ஆதரிக்கவில்லை; பாதுகாப்பான சாவிகளை உருவாக்க முடியாது. புதிய Chrome, Firefox, Safari அல்லது Edge பயன்படுத்தவும்.

அமைப்பை மாற்றினால் புதிய சாவிகள் தானாக உருவாகும்; அதே அமைப்பில் மீண்டும் உருவாக்க பொத்தானைப் பயன்படுத்தவும்.

உருவாக்கப்பட்ட சாவிகள்
உருவாக்கப்படுகிறது…

சீரற்ற மூலமாக குறியாக்கவியல் பாதுகாப்பான crypto.getRandomValues() பயன்படுத்தப்படுகிறது. புதுப்பித்த பின் சாவிகள் சேமிக்கப்படாது; நகலெடுத்து அல்லது பதிவிறக்கி இரகசிய மேலாளரில் வைத்துக்கொள்ளவும்.

குறியாக்க வடிவங்கள்

அதே சீரற்ற பைட்டுகளை வெவ்வேறு உரைக் குறியாக்கங்களில் காட்டலாம். URL, JSON, அமைப்புக் கோப்பு அல்லது நெறிமுறைக்கு ஏற்ற வடிவத்தைத் தேர்ந்தெடுக்கவும்.

HEX2×
0-9 a-f

ஒவ்வொரு பைட்டும் இரண்டு பதினாறும அடையாளங்களால் காட்டப்படுகிறது. நீளம் தெளிவானது; கிட்டத்தட்ட எல்லா மொழிகளும் கருவிகளும் ஆதரிக்கின்றன.

ஏற்றது: அமைப்புக் கோப்புகள், கட்டளை வரி, பதிவுகள் மற்றும் பிழைத்திருத்தம்.

Base64≈1.34×
A-Z a-z 0-9 + / =

சுருக்கமான இரும-உரை குறியாக்கம்; ஆனால் URL அல்லது கோப்புப் பெயரில் +, /, = தப்பித்தல் தேவை.

ஏற்றது: JSON/XML பரிமாற்றம் மற்றும் பொதுவான உரை சேமிப்பு.

Base64URL≈1.34×
A-Z a-z 0-9 - _

- மற்றும் _ பயன்படுத்தி = நிரப்புதலை நீக்கும் URL-பாதுகாப்பான Base64 வடிவம்.

ஏற்றது: JWT, OAuth டோக்கன்கள், குக்கிகள் மற்றும் URL அளவுருக்கள்.

Base32≈1.6×
A-Z 2-7

எழுத்துப் பெரிய/சிறிய வேறுபாடு இல்லை; குழப்பமான 0/O, 1/I/L எழுத்துகள் தவிர்க்கப்படும்.

ஏற்றது: TOTP இரகசியங்கள், DNS பதிவுகள், பட்டைக்குறியீடுகள் மற்றும் கைமுறை உள்ளீடு.

அடிக்கடி கேட்கப்படும் கேள்விகள்

இந்தச் சாவி உருவாக்கி பாதுகாப்பானதா?

ஆம். Math.random-க்கு பதிலாக இயக்க முறைமையின் குறியாக்கவியல் பாதுகாப்பான சீரற்ற மூலத்தைப் பயன்படுத்தும் crypto.getRandomValues பயன்படுத்தப்படுகிறது.

சாவிகள் சேவையகத்திற்கு அனுப்பப்படுகிறதா அல்லது பதிவு செய்யப்படுகிறதா?

இல்லை. உருவாக்கமும் குறியாக்கமும் உலாவியில் நடக்கும்; வரலாறு சேமிக்கப்படாது, புதுப்பித்தால் முடிவுகள் அழியும்.

இவற்றை உள்நுழைவு கடவுச்சொற்களாகப் பயன்படுத்தலாமா?

இவை API சாவி, குறியாக்கச் சாவி, டோக்கன் போன்ற இயந்திர இரகசியங்களுக்கானவை. மனிதக் கடவுச்சொற்களுக்கு கடவுச்சொல் மேலாளரைப் பயன்படுத்தவும்.

இரண்டு சாவிகள் ஒரே மாதிரி இருக்குமா?

கோட்பாட்டில் சாத்தியம்; ஆனால் பரிந்துரைக்கப்பட்ட நீளத்தில் வாய்ப்பு மிகக் குறைவு. 32-பைட் சாவிக்கு 2^256 மதிப்புகள் உள்ளன.

சாவியை எப்படி சேமிக்க வேண்டும்?

நீண்டகாலச் சாவிகளை இரகசிய மேலாளர் அல்லது பாதுகாக்கப்பட்ட சூழல் மாறியில் வையுங்கள்; மூலக் குறியீடு, அரட்டை, பதிவுகளில் இடாதீர்கள், அவ்வப்போது மாற்றுங்கள்.

சாவிகள் இந்த உலாவியிலேயே உருவாக்கப்படுகின்றன; சேவையகத்திற்குப் பதிவேற்றப்படுவதில்லை.
அனைத்து பயனுள்ள கருவிகள் தனியுரிமைக் கொள்கை முகப்பு
