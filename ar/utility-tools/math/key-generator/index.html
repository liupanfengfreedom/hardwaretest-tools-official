مولّد مفاتيح آمنة

أنشئ مفاتيح API ومفاتيح تشفير ورموز وصول آمنة تشفيرياً باستخدام Web Crypto API. اختر HEX أو Base64 أو Base64URL أو Base32؛ كل العمليات تبقى على هذا الجهاز.

⚠ هذه الأداة لبيانات الاعتماد المقروءة آلياً وليست لكلمات المرور التي يجب تذكرها. اختر عدداً كافياً من البايتات وفق متطلبات الأمان.
⛔ لا يدعم هذا المتصفح crypto.getRandomValues، لذلك لا يمكن إنشاء مفاتيح آمنة. استخدم إصداراً حديثاً من Chrome أو Firefox أو Safari أو Edge.

الأسئلة الشائعة

هل مولّد المفاتيح هذا آمن؟

نعم. يستخدم crypto.getRandomValues المعتمد على مصدر عشوائي آمن تشفيرياً في نظام التشغيل بدلاً من Math.random.

هل تُرسل المفاتيح إلى الخادم أو تُسجّل؟

لا. يتم التوليد والترميز داخل المتصفح، ولا يُحفظ سجل، وتختفي النتائج عند تحديث الصفحة.

هل يمكن استخدامها كلمات مرور لتسجيل الدخول؟

هي مخصصة للأسرار المقروءة آلياً مثل مفاتيح API ومفاتيح التشفير والرموز. استخدم مدير كلمات مرور للكلمات التي يكتبها البشر.

هل يمكن أن يتطابق مفتاحان؟

هذا ممكن نظرياً لكنه مهمل عند الأطوال الموصى بها. للمفتاح ذي 32 بايت 2^256 قيمة محتملة.

كيف أحفظ المفتاح؟

احفظ المفاتيح طويلة الأجل في مدير أسرار أو متغير بيئة محمي. لا تضعها في الشفرة أو المحادثات أو السجلات، وبدّلها دورياً.

تُنشأ المفاتيح في هذا المتصفح فقط ولا تُرفع أبداً إلى الخادم.
