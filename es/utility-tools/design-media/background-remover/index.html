Refinamiento manual

Pinta sobre la imagen original: verde Mantén las marcas siempre protegidas. Elige Borrar marcas para borrar un área y pintarla de nuevo.

La selección se expande desde donde hace clic y se detiene en colores fuera de la tolerancia o píxeles transparentes. No saltará a través de un límite a un color que coincida en el otro lado. Este límite no afecta a la eliminación automática del fondo. Los valores más bajos crean límites más estrictos; los cambios se aplican la próxima vez que haga clic.

Flujo de trabajo recomendado y atajos de teclado

Flujo de trabajo recomendado

  1. Sube una imagen y, a continuación, selecciona Eliminar fondo para probar Fine AI de forma predeterminada. Cambie a la IA original y vuelva a ejecutarla para comparar; para fondos sólidos, de tablero de ajedrez o rayas, también puede usar la detección de color.
  2. Compruebe el esquema del sujeto y los espacios cerrados en el panel Resultado. Cambie a un fondo de vista previa blanco u oscuro para detectar los píxeles de borde restantes.
  3. Uso Mantener para restaurar partes del sujeto que se eliminaron, y Eliminar para borrar cualquier fondo restante.
  4. Deje activada la selección inteligente para áreas claramente delimitadas. Selecciona solo los píxeles conectados y no cruza un límite de color diferente.
  5. Para cabello, líneas finas, pequeños detalles o píxeles de bordes difíciles, desactive la selección inteligente, reduzca el tamaño del cepillo y refine localmente. Utiliza las marcas Borrar, Deshacer y Rehacer para ajustar en cualquier momento.
  6. Cuando el borde transparente se vea limpio, descargue el PNG transparente.

La selección inteligente solo incluye píxeles conectados a donde hizo clic y dentro de la tolerancia de color elegida. Un límite de color bloquea la selección, por lo que el blanco coincidente fuera de un anillo no puede seleccionar el blanco coincidente dentro de él. Puede utilizar la selección inteligente tanto con Mantener como con Eliminar; haga clic en cada área desconectada por separado. Los contornos rojos muestran Eliminar áreas y los contornos verdes muestran Mantener áreas. Puedes mostrarlas u ocultarlas de forma independiente y nunca se incluyen en las descargas. Mantenga las áreas como prioridad, así que elimine las acciones omítelas. Elija Borrar marcas para borrar cualquier tipo de marca localmente y, a continuación, vuelva a pintar. Desactive la selección inteligente para realizar ediciones precisas de pinceles de 1 píxel.
Utilice la rueda del ratón para hacer zoom sobre la imagen original, luego arrastre para encuadrar; ambos paneles permanecen alineados. Amplía hasta un 3200% y usa Ajustar para volver a la imagen completa. Las teclas de flecha mueven el pincel un píxel; Space pinta. Pulse Ctrl /Z + Z para deshacer.

01 / Subir

Compara el original y el resultado uno al lado del otro

Las imágenes grandes se redimensionan a un borde máximo de 2048 px. Edite el original a la izquierda y vea el resultado a la derecha.

02 / Refinar

Mostrar qué conservar y eliminar

Utilice el pincel Keep para proteger el sujeto y el pincel Remove para borrar las áreas de fondo. El resultado se actualiza al instante.

03 / Descargar

Exportar un PNG transparente pulido

Oculta las marcas de color para inspeccionar la imagen. Su descarga de PNG incluye todas sus mejoras manuales.
