# 中文图片背景移除

访问路径：`/zh/utility-tools/design-media/background-remover/`。沿用站点的静态 HTML、CSS 和 JavaScript 结构，无构建步骤。通过 HTTP 本地服务或 HTTPS 网站访问，不建议直接双击 HTML 文件。

实现上传与拖放、输入格式和 20 MB 限制、最长边 2048 像素缩放、浏览器端背景移除、原图/结果左右对照、预览底色与透明 PNG 下载。页面只在点击移除时从 esm.sh 加载固定版本 `@imgly/background-removal@1.7.0`，模型资源由库的默认资源服务器提供。网络受限时可能加载失败；正式部署可考虑同源托管模型及引擎资源。

手动修补：在左侧原图使用绿色保留画笔恢复原图内容，使用红色移除画笔擦除区域，右侧结果图实时显示透明效果。可在自动抠图前后标记，重新运行 AI 会继续应用当前标记；笔画重叠处以最后一次为准。支持笔刷大小、撤销/重做、清除标记（可撤销），以及可关闭的彩色标记。下载直接编码右侧结果画布，不包含彩色标记。标记直接修正透明度蒙版，不会向 AI 提交区域提示。

智能扩选默认开启，保留与移除共用规则。每次落笔采样原图的 RGBA 颜色，整个笔画固定使用这个参考色。根据相邻四个方向连通的像素执行局部颜色选择，范围限制在笔尖路径周围的设定半径内；不跨越颜色不匹配区域和全透明间隙。同色但不相连的区域不会被自动选中，除非用户的笔尖路径直接经过该区域。参考像素与候选像素的每个 RGBA 通道差值均不得超过 `容差 × 255 / 100`。容差 0 为完全匹配，默认 12；扩展半径默认 24 个工作图像像素，可调 1–100。它是颜色选择，不是物体语义识别。

智能模式下虚线圆表示扩选半径，普通笔刷直径暂不生效。关闭智能扩选即可使用原来的 1–100 像素笔刷。参数只影响后续笔画，历史记录保存各笔画的参数和参考色，因此撤销、重做、清除标记和重新自动抠图后都能复现同一选择。空白透明像素上落笔不扩选，也不新增历史记录。

原图编辑视口支持 100% 至 3200% 缩放：滚轮以指针位置为中心连续缩放，也可使用加减按钮和“适应”按钮；选择“移动画面”后可拖动放大的原图，中键拖动也可临时移动。两侧画布采用相同的适配尺寸、中心变换原点、缩放倍率和偏移；滚轮、加减按钮、鼠标/触控拖动、中键拖动及键盘移动都会同步到右侧结果，便于对照同一区域。点击“适应”、更换图片或清空时会同时重置两侧视图。平移范围会限制在图片边缘，避免画面完全移出视口。像素显示达到 6 px 时，两侧使用清晰像素缩放，左侧叠加网格；导出仍保持完整工作图像的尺寸与透明度，不受视口裁切影响。

普通笔刷直径以工作图像像素为单位，范围为 1–100 像素，不随缩放倍率改变。1 像素笔刷用 Bresenham 路径写入单个整数像素；更大的圆形笔刷按像素中心到线段的距离栅格化。普通和智能笔刷的保留与移除操作分别写入 255 和 0 的蒙版 Alpha 值，画笔边缘不使用 Canvas 矢量抗锯齿，因此不会产生意外的半透明边缘像素。原图自身的半透明像素在保留后仍保持原有透明度。

鼠标、触控笔和触屏通过 Pointer Events 编辑。键盘聚焦左侧原图后，方向键移动画笔、空格涂抹，Ctrl/Command+Z 撤销、Shift+Ctrl/Command+Z 或 Ctrl/Command+Y 重做。窄屏仍保持左右对照，可横向滚动对比区域。

第三方依赖：IMG.LY background-removal-js，采用 AGPL-3.0 许可；对项目发布方式有许可要求，闭源使用需要评估其商业许可。源代码、完整许可与配置说明见 https://github.com/imgly/background-removal-js 。本页引用该库，不包含或修改第三方库源码。

已检查 JavaScript 语法、页面 HTTP 响应和固定 CDN 模块导出。原生 Canvas 回归测试位于 `scripts/tests/background-remover.test.mjs`，覆盖擦除/恢复、连续笔画、撤销/重做、AI 与手动标记合并、取消笔画、坐标缩放、视点缩放与平移边界、原图透明度和 PNG 导出，也覆盖智能扩选的颜色边界、范围限制、固定参考色、透明间隙、参数快照和普通笔刷兼容性。测试通过 `node --test scripts/tests/background-remover.test.mjs` 运行，需要测试环境可解析 `@napi-rs/canvas`（可通过 NODE_PATH 指向已有运行时依赖）；页面本身不需要这个依赖。
