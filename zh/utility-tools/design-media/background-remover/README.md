# 中文图片背景移除

访问路径：`/zh/utility-tools/design-media/background-remover/`。沿用站点的静态 HTML、CSS 和 JavaScript 结构，无构建步骤。通过 HTTP 本地服务或 HTTPS 网站访问，不建议直接双击 HTML 文件。

实现上传与拖放、输入格式和 20 MB 限制、最长边 2048 像素缩放、浏览器端背景移除、原图/结果左右对照、预览底色与透明 PNG 下载。页面只在点击移除时从 esm.sh 加载固定版本 `@imgly/background-removal@1.7.0`，模型资源由库的默认资源服务器提供。网络受限时可能加载失败；正式部署可考虑同源托管模型及引擎资源。

支持 Ctrl+V 粘贴截图或复制的图片，Mac 使用 Command+V。页面从用户触发的 `paste` 事件获取第一张图片文件，兼容 `clipboardData.items` 与 `clipboardData.files`，沿用上传的 JPG、PNG、WebP 格式校验、20 MB 限制和缩放处理。无需主动读取剪贴板或申请剪贴板读取权限；纯文本及图片网址不会作为图片导入。粘贴新图片会替换当前图片并重置手动标记与视口；正在自动处理或绘制时提示稍后粘贴。连续粘贴采用最近一次有效的图片读取请求，防止较早的解码结果覆盖新图片。

手动修补：在左侧原图使用绿色保留画笔恢复原图内容，使用红色移除画笔擦除区域，右侧结果图实时显示透明效果。可在自动抠图前后标记，重新运行 AI 会继续应用当前标记。保留区始终优先：普通或智能保留标记建立像素保护，后续普通移除、智能移除及自动抠图都不能擦掉这些像素，也不会将其绿色标记覆盖为红色；后标记保留也能恢复已移除的原图像素。隐藏彩色标记不影响保护。局部擦除保留标记、撤销对应保留操作或清除全部标记后解除保护，重做保留或撤销擦除、清除会恢复保护。支持笔刷大小、撤销/重做、清除全部标记（可撤销），以及可关闭的彩色标记。下载直接编码右侧结果画布，不包含彩色标记或边界线。标记直接修正透明度蒙版，不会向 AI 提交区域提示。

“擦除标记”工具在左侧原图按笔刷范围清除绿色保留或红色移除标记，同时解除相应像素的保护，使该区域可以重新标记为保留或移除。擦除始终使用普通笔刷，直径可调 1–100 个工作图像像素，支持连续拖动、1 像素精修及键盘操作；切回保留或移除时沿用原先的智能扩选设置。被擦区域恢复到当前自动抠图的透明度蒙版，尚未自动抠图时恢复原图。擦除会清掉该位置先前所有手动标记，其他区域维持当前状态；重新自动抠图后按新的自动结果恢复擦除区域。撤销或取消擦除可恢复此前标记与保护，重做擦除可再次解除。擦除本身不会新增彩色标记。

智能扩选默认开启，保留与移除共用规则。每次点击采样原图的 RGBA 颜色，从点击位置沿上下左右四个方向连续扩选，仅选择相连且符合颜色容差的非全透明像素。超出容差的颜色与全透明区域阻止扩选，不会跨过异色边界或对角接触点选择另一侧的同色区域；例如点击圈外白底，不会选择被金色轮廓包围的圈内白色。参考像素与候选像素的每个 RGBA 通道差值均不得超过 `容差 × 255 / 100`，所有比较均使用最初取样颜色，避免渐变色累积漂移。容差 0 为完全匹配，默认 50，可调 0–100；容差越大，能够跨过的颜色差异越大。选择不受当前缩放视口限制，它是颜色连通选择，不是物体语义识别。

智能模式下小圆点标记取色位置，普通笔刷直径暂不生效。每次按下鼠标或触控笔只进行一次连通扩选，拖动不会跳到新的区域；另一块不相连的同色区域需要单独点击。关闭智能扩选即可使用原来的 1–100 像素笔刷。容差调整后再次点击生效，历史记录保存各次操作的容差和原图取样位置，因此撤销、重做、清除标记和重新自动抠图后都能复现同一选择。空白透明像素上落笔不扩选，也不新增历史记录。

“显示选区边界线”默认开启，可独立于彩色标记显示：红线表示移除区，绿线表示保留区。边界由实际生效的标记生成，包含已保护像素及局部擦除后的边缘，随撤销、重做、清除、缩放和平移同步更新。边界使用独立画布，完全不参与结果合成及 PNG 导出。

原图编辑视口支持 100% 至 3200% 缩放：滚轮以指针位置为中心连续缩放，也可使用加减按钮和“适应”按钮；选择“移动画面”后可拖动放大的原图，中键拖动也可临时移动。两侧画布采用相同的适配尺寸、中心变换原点、缩放倍率和偏移；滚轮、加减按钮、鼠标/触控拖动、中键拖动及键盘移动都会同步到右侧结果，便于对照同一区域。点击“适应”、更换图片或清空时会同时重置两侧视图。平移范围会限制在图片边缘，避免画面完全移出视口。像素显示达到 6 px 时，两侧使用清晰像素缩放，左侧叠加网格；导出仍保持完整工作图像的尺寸与透明度，不受视口裁切影响。

普通笔刷直径以工作图像像素为单位，范围为 1–100 像素，不随缩放倍率改变。1 像素笔刷用 Bresenham 路径写入单个整数像素；更大的圆形笔刷按像素中心到线段的距离栅格化。普通和智能笔刷的保留与移除操作分别写入 255 和 0 的蒙版 Alpha 值，画笔边缘不使用 Canvas 矢量抗锯齿，因此不会产生意外的半透明边缘像素。原图自身的半透明像素在保留后仍保持原有透明度。

普通保留、普通移除和擦除标记的光标尺寸严格对应直径滑条的图片像素数，随图片适配和视口缩放同步变化。直径为 1 时使用贴齐目标像素格的方块，大于 1 时显示相应直径的圆形范围。指示块采用内部描边，无撑大尺寸的固定边框或外阴影；显示指示块时隐藏系统十字光标。滑条变化或视口尺寸变化会同步重算指示块位置和大小。

鼠标、触控笔和触屏通过 Pointer Events 编辑。键盘聚焦左侧原图后，方向键移动画笔、空格涂抹，Ctrl/Command+Z 撤销、Shift+Ctrl/Command+Z 或 Ctrl/Command+Y 重做。窄屏仍保持左右对照，可横向滚动对比区域。
