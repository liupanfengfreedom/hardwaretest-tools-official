సురక్షిత కీ జనరేటర్

బ్రౌజర్ Web Crypto APIతో క్రిప్టోగ్రాఫిక్‌గా సురక్షిత API కీలు, ఎన్‌క్రిప్షన్ కీలు, యాక్సెస్ టోకెన్లు తయారు చేయండి. HEX, Base64, Base64URL లేదా Base32 ఎంచుకోండి; అన్నీ ఈ పరికరంలోనే జరుగుతాయి.

⚠ ఈ సాధనం యంత్రం చదివే రహస్యాల కోసం, గుర్తుంచుకోవాల్సిన లాగిన్ పాస్‌వర్డ్‌ల కోసం కాదు. భద్రత అవసరానికి తగిన బైట్లు ఎంచుకోండి.
⛔ ఈ బ్రౌజర్ crypto.getRandomValuesకు మద్దతు ఇవ్వదు కాబట్టి సురక్షిత కీలు తయారు చేయలేము. తాజా Chrome, Firefox, Safari లేదా Edge వాడండి.

256 బిట్లు చాలా అధిక బలం
ఎన్‌కోడింగ్

సెట్టింగ్ మార్చితే కొత్త కీలు స్వయంచాలకంగా తయారవుతాయి; అదే సెట్టింగ్‌తో మళ్లీ తయారు చేయడానికి బటన్ వాడండి.

తయారైన కీలు
తయారవుతోంది…

యాదృచ్ఛిక మూలం: crypto.getRandomValues(), ఇది క్రిప్టోగ్రాఫిక్‌గా సురక్షితం. రిఫ్రెష్ తర్వాత కీలు నిల్వ ఉండవు; కాపీ లేదా డౌన్‌లోడ్ చేసి సీక్రెట్ మేనేజర్‌లో ఉంచండి.

ఎన్‌కోడింగ్ ఫార్మాట్లు

అదే యాదృచ్ఛిక బైట్లను వేర్వేరు టెక్స్ట్ ఎన్‌కోడింగ్‌లలో చూపవచ్చు. URL, JSON, కాన్ఫిగరేషన్ ఫైల్ లేదా ప్రోటోకాల్‌కు సరిపోయే ఫార్మాట్ ఎంచుకోండి.

HEX2×
0-9 a-f

ప్రతి బైట్‌ను రెండు హెక్సాడెసిమల్ అక్షరాలతో చూపుతుంది. పొడవు ఖచ్చితం, దాదాపు అన్ని భాషలు మరియు సాధనాలు మద్దతిస్తాయి.

దీనికి సరైనది: కాన్ఫిగరేషన్ ఫైళ్లు, కమాండ్ లైన్, లాగ్‌లు, డీబగ్గింగ్.

Base64≈1.34×
A-Z a-z 0-9 + / =

కాంపాక్ట్ బైనరీ-టు-టెక్స్ట్ ఫార్మాట్; URL లేదా ఫైల్ పేర్లలో +, /, = ఎస్కేప్ చేయాలి.

దీనికి సరైనది: JSON/XML బదిలీ మరియు సాధారణ టెక్స్ట్ నిల్వ.

Base64URL≈1.34×
A-Z a-z 0-9 - _

- మరియు _ వాడి = ప్యాడింగ్ తీసేసే URL-సురక్షిత Base64 రూపం.

దీనికి సరైనది: JWT, OAuth టోకెన్లు, కుకీలు, URL పారామీటర్లు.

Base32≈1.6×
A-Z 2-7

కేస్‌పై ఆధారపడదు; గందరగోళం కలిగించే 0/O, 1/I/L అక్షరాలు ఉండవు.

దీనికి సరైనది: TOTP రహస్యాలు, DNS రికార్డులు, బార్‌కోడ్‌లు, చేతితో నమోదు.

తరచుగా అడిగే ప్రశ్నలు

ఈ కీ జనరేటర్ సురక్షితమేనా?

అవును. ఇది Math.randomకు బదులుగా ఆపరేటింగ్ సిస్టమ్ క్రిప్టోగ్రాఫిక్ సురక్షిత యాదృచ్ఛిక మూలంతో crypto.getRandomValues వాడుతుంది.

కీలు సర్వర్‌కు పంపబడతాయా లేదా నమోదు అవుతాయా?

లేదు. తయారీ, ఎన్‌కోడింగ్ బ్రౌజర్‌లోనే జరుగుతాయి; చరిత్ర నిల్వ ఉండదు, రిఫ్రెష్ చేస్తే ఫలితాలు తొలగుతాయి.

వీటిని లాగిన్ పాస్‌వర్డ్‌లుగా వాడవచ్చా?

ఇవి API కీలు, ఎన్‌క్రిప్షన్ కీలు, టోకెన్ల వంటి యంత్రం చదివే రహస్యాల కోసం. మానవ పాస్‌వర్డ్‌లకు పాస్‌వర్డ్ మేనేజర్ వాడండి.

రెండు కీలు ఒకేలా ఉండవచ్చా?

సిద్ధాంతంగా సాధ్యం, కానీ సిఫారసు పొడవులో అవకాశం అతి తక్కువ. 32-బైట్ కీకి 2^256 విలువలు ఉంటాయి.

కీని ఎలా భద్రపరచాలి?

దీర్ఘకాలిక కీలను సీక్రెట్ మేనేజర్ లేదా రక్షిత ఎన్విరాన్‌మెంట్ వేరియబుల్‌లో ఉంచండి; కోడ్, చాట్, లాగ్‌లలో పెట్టవద్దు, క్రమం తప్పకుండా మార్చండి.

కీలు ఈ బ్రౌజర్‌లో మాత్రమే తయారవుతాయి; సర్వర్‌కు ఎప్పుడూ అప్‌లోడ్ కావు.
అన్ని ఉపయోగకర సాధనాలు గోప్యతా విధానం హోమ్
