기본적으로 고급 AI를 사용합니다. 지원되지 않거나 실패하면 자동으로 원래 AI로 돌아갑니다. 모델은 첫 사용 시 다운로드됩니다.

이미지를 선택하거나 Ctrl + V (Mac에서는 ⌘ V) 로 붙여넣습니다.

수동 정제

원본 이미지에 페인트 칠하기: 녹색 유지 표시는 항상 보호됩니다. 영역을 지우고 다시 칠하려면 지우기 표시를 선택합니다.

선택 영역은 클릭한 위치에서 확장되며 허용 오차 또는 투명한 픽셀을 벗어난 색상에서 중지됩니다. 그것은 경계를 넘어 반대편의 일치하는 색상으로 점프하지 않습니다. 이 제한은 자동 배경 제거에는 영향을 미치지 않습니다. 낮은 값은 더 엄격한 경계를 만듭니다. 변경 사항은 다음에 클릭할 때 적용됩니다.

권장 워크플로우

  1. 이미지를 업로드한 다음 배경 제거 기본적으로 Fine AI를 시도합니다. 원본 AI로 전환하고 비교를 위해 다시 실행하십시오. 솔리드, 체커보드 또는 스트라이프 배경의 경우 색상 감지를 사용할 수도 있습니다.
  2. 결과 패널에서 주제 개요와 동봉된 간격을 확인합니다. 흰색 또는 어두운 미리보기 배경으로 전환하여 나머지 가장자리 픽셀을 찾습니다.
  3. 사용 유지 제거된 피험자의 일부를 복원하고 삭제 나머지 배경을 지울 수 있습니다.
  4. 명확하게 경계가 있는 영역은 스마트 선택을 켜두세요. 연결된 픽셀만 선택하고 다른 색상 경계를 넘지 않습니다.
  5. 머리카락, 얇은 선, 작은 디테일 또는 뻣뻣한 가장자리 픽셀의 경우 스마트 선택을 끄고 브러시 크기를 줄인 다음 로컬로 수정하십시오. 지우기 표시, 실행 취소 및 다시 실행을 사용하여 언제든지 조정할 수 있습니다.
  6. 투명 가장자리가 깨끗해 보이면 투명 PNG를 다운로드하십시오.

스마트 선택에는 클릭한 위치와 선택한 색상 허용 오차 내에 연결된 픽셀만 포함됩니다. 색상 경계는 선택을 차단하므로 링 외부의 흰색과 일치하는 것은 링 내부의 흰색과 일치하는 것을 선택할 수 없습니다. 스마트 선택을 유지 및 제거와 함께 사용할 수 있습니다. 분리된 각 영역을 개별적으로 클릭하십시오. 빨간색 윤곽선은 영역 제거를 나타내고 녹색 윤곽선은 영역 유지 를 나타냅니다. 표시하거나 숨길 수 있습니다 독립적으로 다운로드에 포함되지 않습니다. 영역은 우선순위를 유지하므로 삭제 작업은 건너뜁니다. 지우기 표시를 선택하여 두 가지 유형의 표시를 로컬로 지운 다음 다시 페인트합니다. 정확한 1픽셀 브러시 편집을 위해 스마트 선택을 끕니다.
마우스 휠을 사용하여 원본 이미지를 확대한 다음 드래그하여 이동합니다. 두 패널이 일직선을 유지합니다. 최대 3200% 까지 확대하고 핏을 사용하여 전체 이미지로 돌아갑니다. 화살표 키는 브러시를 한 픽셀 이동하고 공간 페인트를 이동합니다. 실행을 취소하려면 Ctrl/⌘ + Z를 누르세요.

01/업로드

원본과 결과를 나란히 비교

큰 이미지는 최대 2048픽셀의 가장자리로 크기가 조정됩니다. 왼쪽에서 원본을 편집하면 오른쪽에서 결과를 볼 수 있습니다.

02/정제

보관 및 삭제할 사항 표시

브러시를 사용하여 피사체를 보호하고 브러시를 제거하여 배경 영역을 지웁니다. 결과는 즉시 업데이트됩니다.

03/다운로드

세련된 투명 PNG 내보내기

색상 표시를 숨겨 이미지를 검사합니다. PNG 다운로드에는 수동으로 다듬은 내용이 모두 포함되어 있습니다.
